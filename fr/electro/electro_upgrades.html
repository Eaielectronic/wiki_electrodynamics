Modules d'amélioration

Publicité

Comment installer une amélioration

Ouvrez l'interface d'une machine compatible et placez le module d'amélioration dans le slot dédié. Plusieurs modules peuvent être combinés selon la machine.

Types de modules

ModuleEffetCoût
Amélioration de vitesse Augmente la vitesse de traitement de la machine Consommation d'énergie accrue
Amélioration d'efficacité Réduit la consommation d'énergie par opération Vitesse légèrement réduite
Amélioration de capacité Augmente la taille des réservoirs internes (fluides/gaz) Aucun coût supplémentaire
Amélioration de rendement Augmente la quantité de produit par opération Consommation d'énergie accrue

Stratégie

Combinez vitesse + efficacité pour un bon équilibre. Pour les machines critiques (broyeur, électrolyseur), privilégiez le rendement pour maximiser la production de ressources rares.
