Outils

Publicité

Multimètre portable

Faites un clic droit sur n'importe quel câble pour afficher dans le chat les données du réseau :

  • Courant actuel / intensité nominale
  • Tension de fonctionnement
  • Puissance transmise (W)
  • Résistance totale et perte par résistance
  • Machine à tension la plus basse connectée

Version bloc

Le bloc multimètre offre les mêmes informations mais les affiche en permanence dans son interface. Idéal pour surveiller un réseau en continu.

Clé à molette

Outil polyvalent pour modifier les machines et blocs en jeu :

  • Fusionner 9 turbines en une grande turbine 3×3 (Nuclear Science)
  • Configurer certaines machines
  • Démonter des blocs sans les casser

Cisailles

Clic droit sur un câble isolé posé pour retirer l'isolation. Utile pour modifier un réseau existant sans tout recasser.

Carte chromatographique

Outil d'analyse pour identifier les composants chimiques. Utilisé avec certaines machines de traitement avancé.
