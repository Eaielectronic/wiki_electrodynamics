Conseils pratiques

Publicité

Électricité

  • Toujours vérifier la tension requise d'une machine avant de la connecter
  • Utiliser des disjoncteurs pour protéger les machines en aval
  • Garder les segments à fort courant courts pour minimiser les pertes
  • Les câbles colorés permettent de faire passer plusieurs lignes côte à côte sans les relier
  • Ne jamais toucher un transformateur sous tension — il tue instantanément

Ressources

  • Toujours broyer les minerais avant de les fondre — double le rendement
  • L'acier est la ressource la plus utilisée — produisez-en en grande quantité dès le début
  • L'uranium est radioactif — portez une combinaison Hazmat pour le manipuler

Machines

  • Installez JEI pour voir toutes les recettes facilement
  • Les modules d'amélioration de vitesse augmentent la consommation — assurez une alimentation stable
  • La chambre d'électrolyse est indispensable pour produire du deutérium (réacteur à fusion)

Vers Nuclear Science

  • Maîtrisez l'électricité à 480 V avant de commencer Nuclear Science
  • Produisez du plomb pour le blindage radiation dès que possible
  • Le vanadium est nécessaire pour les tuyaux VS-Céramique du réacteur MS
