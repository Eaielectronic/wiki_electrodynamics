Tunnel quantique

Publicité

Transport instantané

Le tunnel quantique transporte énergie, fluides, gaz et items entre deux points à n'importe quelle distance, instantanément. Similaire au Tesseract de Thermal Expansion.

Ce que le tunnel peut transporter

TypeSous-types
ÉlectricitéUn seul voltage/paquet à la fois par fréquence
FluidesUn seul fluide à la fois par fréquence
GazUn seul gaz à la fois par fréquence
ItemsTous types

Indépendance des réseaux

Les propriétés du câble émetteur (résistance, voltage) n'affectent pas le câble récepteur. Chaque côté est indépendant.

Les fréquences

Chaque tunnel est lié à une fréquence. Tous les tunnels partageant la même fréquence échangent les mêmes données. Il existe deux types :

TypeVisibilitéModification
PrivéeVous seulVous seul
PubliqueTous les joueursCréateur uniquement

Créer une fréquence

  1. Ouvrez l'interface du tunnel
  2. Cliquez sur Nouvelle fréquence
  3. Nommez-la et choisissez le type (privée/publique)
  4. Cliquez sur Créer

Activer une fréquence

  1. Cliquez sur la fréquence dans la liste pour la sélectionner
  2. Appuyez sur ✓ pour lier le tunnel à cette fréquence
  3. Appuyez sur ✗ pour désactiver

Configurer les entrées/sorties

Cliquez sur Config E/S pour définir le rôle de chaque face du bloc (entrée, sortie, ou inactif). Recliquez pour masquer le sélecteur.

Surveiller le trafic

Survolez l'onglet Tampon dans l'interface pour voir les quantités en cours de transport sur la fréquence.

Chunk chargé obligatoire

Un tunnel quantique doit être dans un chunk chargé pour fonctionner. Utilisez un Chargeur de chunks si nécessaire.
